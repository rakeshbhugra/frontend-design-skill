# Pricing Page

Help the visitor choose a plan and feel good about it. The job is reducing uncertainty, not showing prices.

Reach for `landing-page.md` instead when there is one offer and no tiers. Reach for `operational-enterprise.md` when every deal is sales-led and the page is really a qualification form.

Gather first: value metric (seat, usage, project), plan names and monthly/annual prices, the 3-6 limits that matter, the upgrade trigger, top 3 objections, risk reversal available.

Layout, pick one: A classic 3-card (three natural tiers), B value-metric slider (usage pricing, keep a median default), C pick-your-path (two columns by persona, then price), D enterprise last mile (self-serve plus sales-led).

## Section order

1. Value headline: outcome, for whom.
2. Monthly/annual toggle with the annual savings callout.
3. Plan table: 3 plans (or 2), one Recommended, consistent CTA verbs, a "Compare plans" link.
4. Comparison matrix grouped Core, Collaboration, Admin/Security, Support. Highlight what changes per tier.
5. Social proof next to the decision point.
6. Security, compliance, procurement (B2B).
7. FAQ: cancel anytime, hitting limits, discounts, freelancers vs teams, security and data.
8. Final CTA plus contact sales.

## Numbers

| Number | Default | Failure prevented |
|---|---|---|
| Plans | 3 max | Analysis paralysis |
| Recommended plan | 1, strongest tinted surface | Nothing to anchor the choice |
| Visible limits per plan | 3-6 | Spreadsheet table |
| Included items per plan | 3-6 | Feature list nobody reads |
| Plan description | 2 lines: who it is for, what it unlocks | Plans described by internal features |
| FAQ | 6-12 Q/A | Objections that bounce |
| Value metric | 1 page-wide | Switching units mid-page |
| Demo price ladder | $18, $42, $96 | Tiers too close to differentiate |
| Mobile table | Stacked cards | Horizontal scroll |

## Signature moves

- Recommended plan styled quietly: tint, not shouting.
- Bullets written as outcomes: "Ship unlimited client sites without extra fees", not "Unlimited projects".
- "Save X%" on annual; "Starting at" only when pricing is truly variable.
- Enterprise column reads as procurement reassurance.
- Billing toggle is keyboard accessible with one obvious active state.

## Do not

- Hide pricing behind "Contact sales" for everything.
- Mix CTA verbs across plans ("Get started" / "Try now" / "Sign up").
- Add surprise fees or unexplained overages.
- Over-design the table until readability drops.
- List features with no context for why they matter.

## Effects it may use

- `container-lines` behind the table.
- `number-details` on the price figures.
